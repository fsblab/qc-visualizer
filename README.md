# qc-visualizer
Quantum Computing Visualizer in real time to quickly build circuits and see the results after each individual step.

The project consists of two branches: "single-qubit-gates" and "multi-qubit-gates"

## single-qubit-gates
This branch focuses on simulating a quantum computer exclusively with gates sized 1. This helps understand what happens to each individual qubit without entanglement and allows for visualization with help of the Bloch-Sphere.

## multi-qubit-gates
This branch focuses on simulating a complete quantum computer, including control gates. In this regard it makes use of a state vector.
